DPE Python documentation¶

The Python package prepares the Defence and Peace Economics catalogue, discovers and updates research topics, builds citation networks, and exports validated releases for a static JavaScript application. Python runs during data preparation; the published website does not require a Python process, database or hosted model.

Start with Getting started to build the documentation or use the parser. See Operational workflows before training or updating a release, and Architecture for the boundaries between pure helpers, analysis and orchestration. The Python API reference links each module to its source and public members.
