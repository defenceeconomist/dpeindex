DPE Python documentation
========================

The Python package prepares the Defence and Peace Economics catalogue, discovers
and updates research topics, builds citation networks, and exports validated
releases for a static JavaScript application. Python runs during data preparation;
the published website does not require a Python process, database or hosted model.

Start with :doc:`getting-started` to build the documentation or use the parser.
See :doc:`workflows` before training or updating a release, and :doc:`architecture`
for the boundaries between pure helpers, analysis and orchestration. The
:doc:`api/index` links each module to its source and public members.
