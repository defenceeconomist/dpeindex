MCP stdio tools¶

Expose the four async tools used to fetch, update, inspect and resume the local model. Sphinx mocks the transport dependencies for inspection; the generated signatures and docstrings come from the actual Python source. Importing this module does not run the stdio server; executing it as __main__ does.

DPE RePEc fetch and incremental model tools over MCP stdio.

async app.mcp_server.dpe_fetch_redif() → dict[str, Any][source]¶

Download the complete DPE catalogue from RePEc FTP into a new local snapshot.

Returns snapshot_id, SHA-256, provenance, article count and changes versus the current model. Validates all records; never overwrites the bundled source.

async app.mcp_server.dpe_update_model(snapshot_id: str, through: str | None = None, device: Literal['auto', 'cpu', 'mps', 'cuda'] = 'auto', without_citations: bool = False, allow_removals: bool = False) → dict[str, Any][source]¶

Start an incremental model update from a fetched snapshot and return workspace_id.

Includes every issue unless through (e.g. 37:6) is supplied. Preserves model identity, labels and historical assignments. Rejects removals unless explicitly allowed. Citation review and browser verification precede local activation. without_citations explicitly omits citation analysis. Poll dpe_update_status.

async app.mcp_server.dpe_update_status(workspace_id: str | None = None) → dict[str, Any][source]¶

Read job stages, errors, review/report paths; omit workspace_id for the current model.

async app.mcp_server.dpe_resume_update(workspace_id: str) → dict[str, Any][source]¶

Resume a failed/interrupted update after resolving errors or citation review.

Completed stages are hash-verified and reused. To resolve review_required, inspect the returned review path, edit that workspace’s inputs/decisions.json, then resume. Corrupt completed artifacts require a fresh workspace.
