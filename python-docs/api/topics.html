Topic discovery¶

Embedding, UMAP/HDBSCAN search, keyword representations, quality evaluation and snapshot assembly. Heavy dependencies are imported when the analysis functions are called, not on module import.

Explicit, local-only BERTopic builds. No hosted inference or generative labels.
